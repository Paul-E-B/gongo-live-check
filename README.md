# gongo-live-check
An edge extension to check if gongo is live

To install:
  1. Unzip it somewhere you won't delete (Edge loads it from that folder, not a copy)
  2. Edge → type edge://extensions in the address bar
  3. Turn on Developer mode (left sidebar)
  4. Load unpacked → pick the unzipped folder
  5. Puzzle-piece icon in the toolbar → click the eye next to "Gongo Live Check" to pin it
